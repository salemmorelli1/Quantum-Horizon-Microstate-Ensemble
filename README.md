A research-grade PyTorch framework for differentiable sampling of LQG-inspired
quantum-horizon area ensembles with Hamiltonian Monte Carlo.

The project investigates whether continuous relaxations can provide scalable
proposals for high-dimensional puncture configurations while retaining a clear
statistical boundary between a smooth proxy ensemble and exact discrete quantum
state counting.

## Research question

For spins

\[
j_i\in\left\{\frac12,1,\frac32,\ldots\right\},
\]

the LQG area eigenvalue is

\[
A(\mathbf j)=8\pi\gamma\ell_p^2
\sum_{i=1}^{N}\sqrt{j_i(j_i+1)}.
\]

The repository relaxes each spin through

\[
x_i=\frac12+\log(1+e^{z_i}),
\]

and samples the proper latent density generated by

\[
U(\mathbf z)=
\frac{\kappa_A}{2}(\widetilde A-A_\star)^2
+\kappa_Q\sum_i\sin^2(2\pi x_i)
-\eta\sum_i\log(2x_i+1)
-\sum_i\log\sigma(z_i).
\]

The final term is the Softplus transformation Jacobian. Without it, the latent
target is improper as any coordinate tends to negative infinity.

## Canonical research stack

The auditable execution order mirrors Problem 1:

**Part 0 → Part 1 → Part 2 → Part 3 → Part 4**

1. `part0_validate_model.py` validates the measure, area domain, and gradients.
2. `part1_sample_relaxed_ensemble.py` runs adaptive-warmup HMC.
3. `part2_quantization_diagnostics.py` measures area-shell and lattice behavior.
4. `part3_entropy_geometry.py` analyzes scalable curvature and entropy boundaries.
5. `part4_validate_repository.py` runs the numerical test suite.

`run_research_pipeline.py` executes the complete sequence and stops on the first
failed stage.

## Methodological safeguards

- The Softplus Jacobian is included so the latent density is proper.
- The factorized term \(\prod_i(2x_i+1)\) is labeled a degeneracy **proxy**. It
  is not the dimension of the invariant intertwiner space.
- Continuous samples do not land exactly on the half-integer lattice. Rounding
  is diagnostic only and requires an exact discrete correction for inference.
- The comb potential creates finite barriers. It concentrates probability near
  the lattice but does not guarantee rapid inter-well mixing.
- Warmup adaptation is disabled before samples are retained.
- Single-chain acceptance and scalar ESS do not certify convergence. Constant
  or fewer-than-four-draw traces have unidentified ESS, reported as `null`.
- The thermodynamic-integration field is `d log Z / d kappa_Q = -E[Q]`.
- Gradients are never clipped because clipping would change the Hamiltonian.
- No physical entropy is reported without normalizing-constant estimation and
  exact degeneracy correction.
- This is an LQG-inspired ensemble. A string-theory comparison requires a
  separate charge-constrained microstate model.

## Quick start

Run the validated research pipeline:

```bash
python run_research_pipeline.py
```

Use `--output-root PATH` to isolate a run's artifacts and `--seed INTEGER` to
override the configured seed. Paths are resolved from the caller's directory.
Parts 1–3 preserve the actual seed, run ID, configuration digest, source digest,
and sample-file digest. Old `samples.pt` files without schema-2 provenance must
be regenerated; the audited pipeline will reject them.

Sampling reports use `WARN` or `DIAGNOSTICS_ONLY` for exploratory runs and
`FAIL` for a fully stuck/rejected chain. A successful process exit means the
pipeline executed; inspect `convergence_status` and `diagnostic_warnings`
before using estimates. `NOT_ASSESSED_SINGLE_CHAIN` explicitly means that
multichain convergence has not been assessed. The scalar ESS < 50 warning is
an exploratory heuristic, not a confirmatory sampling threshold.

Or use the installed CLI:

```bash
qhme validate --config configs/baseline.json
qhme sample --config configs/baseline.json
```

The default run writes:

```text
artifacts/part0/model_validation.json
artifacts/part1/samples.pt
artifacts/part1/hmc_summary.json
artifacts/part2/quantization_summary.json
artifacts/part3/geometry_summary.json
artifacts/part4/validation_summary.json
```

## Current research boundary

The code targets a proper relaxed ensemble without estimating its normalizing
constant. The implemented sampler is HMC; a NUTS backend is not implemented.
It does not yet identify an
absolute microcanonical count. The next confirmatory stage requires a
comb-tempered replica ladder, thermodynamic integration or bridge sampling, and
an exact `SU(2)` intertwiner/Chern–Simons correction after discrete recovery.

The [2026-10-11 scientific audit](docs/SCIENTIFIC_AUDIT_2026-10-11.md) records
the corrections and current evidence. The existing PDF describes a historical
baseline; its acceptance and ESS values should not be substituted for current
run diagnostics.
